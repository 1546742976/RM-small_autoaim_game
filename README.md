# RM-small_autoaim_game · 急停射击训练场

面向 RM 视觉组入门的单机 3D 第一人称训练游戏。使用 Godot + GDScript；不包含机器人、联网、外部服务或炸弹模式。第一版采用灰盒场景，练习瞄准、急停时机和弹药管理。

## 当前状态

第一版已完成：灰盒训练场、三把武器、急停射击、护甲、购买、暂停、结算与重开均可运行。Windows x64 发布包位于 `builds/windows/`，双击 `RMPrecisionLab.exe` 即可，无需安装 Godot。便携压缩包为 `builds/RMPrecisionLab-windows-x64.zip`。

本版不包含精细角色／枪械美术、联网、机器人、跳跃或蹲伏；靶子只有固定路线运动。没有引入原草案中的 Gobot 接口或二值减伤护甲。

## 游玩流程与操作

主菜单 → 15 秒购买 → 60 秒训练 → 成绩结算 → 重开。每回合恢复 $5000、100 生命、无甲及免费沙鹰。正式训练开始时重置位置、靶子和统计。

| 操作 | 功能 |
|---|---|
| WASD | 移动；松键减速，反向按键更快减速 |
| 鼠标 | 瞄准 |
| 鼠标左键 | 点击一次尝试发射一发；不支持按住连射 |
| R | 换弹 |
| B | 购买阶段查看／关闭装备面板 |
| E | 购买阶段靠近左侧测试装置，测试护甲结算 |
| Esc | 暂停／继续并释放／捕获鼠标 |

无跳跃、蹲伏、冲刺、自动急停、随机散布、弹道下坠或累积后坐力。射线命中准星中心位置，墙体阻挡射线。

## 射击、弹药和伤害规则

仅当 **当前水平速度 / 正常最大移动速度 < 0.34**、冷却结束、弹夹非空且未换弹时开火。失败点击不扣弹、不计射击数、不排队补射。

| 武器 | 弹夹 / 备弹 | 最小射击间隔 | 躯干伤害 | 换弹时间（可调） | 价格（可调） |
|---|---:|---:|---:|---:|---:|
| 沙鹰 | 7 / 14 | 225 ms | 45 | 2.2 秒 | $700（默认配发免费） |
| AK-47 | 25 / 50 | 100 ms | 40 | 2.5 秒 | $2700 |
| M4A1 | 30 / 60 | 90 ms | 30 | 3.1 秒 | $3100 |

- 每回合总弹药为三个满弹夹；提前换弹保留余弹，只从备弹扣补足部分。备弹不足则装入剩余弹药。
- 空弹夹且有备弹时自动换弹；满弹夹或无备弹时不能换弹。换弹允许移动，禁止射击。
- 最后一发先结算命中与击杀，再检查弹夹及备弹是否均为零；弹尽提前结算。
- 生命上限 100；护甲价格 $1000，耐久上限 100。躯干伤害先扣护甲，溢出扣生命，**没有减伤**。
- 所有武器爆头绕过护甲直接击杀。例如 AK 命中只有 10 护甲的躯干：扣 10 护甲、30 生命。

## 购买、训练靶与统计

- 购买阶段可确认一次装备：保留默认沙鹰不扣钱；AK 或 M4 替换沙鹰；可同时购买护甲。确认后不能重复扣款或刷弹药，未确认则保留默认装备。
- 15 秒后进入训练；购买阶段不允许射击靶子，训练阶段不能购买或换枪。
- 六个靶子：三个静止、三个固定路线往返，混合无甲和满甲；均为 100 生命，有独立头部与躯干判定。击倒 1 秒后恢复初始状态刷新。不攻击玩家，无自主决策。
- 购买阶段的伤害测试装置可手动触发 40 点躯干伤害：显示扣甲／扣血前后结果，再恢复生命与已购护甲；不计入成绩。
- 命中率 = 命中靶子发数 / 实际发射数；爆头率 = 爆头击杀数 / 总击杀数；零分母显示 0%。
- 暂停冻结移动、射击冷却、换弹、靶子刷新与回合倒计时。重开不继承任何回合状态。

## 开发结构

工程位于 `射击游戏/`，入口为 `scenes/main.tscn`；场景中的场地、靶子和界面由脚本构建，运行后可见。

| 模块（位于 `scripts/`） | 职责 |
|---|---|
| `main.gd` | 回合阶段、购买、输入协调、射线、成绩与音效 |
| `game_rules.gd` | 唯一武器参数表、护甲伤害和购买计算 |
| `weapon_controller.gd` | 单发冷却、弹药、换弹与开火许可 |
| `player_controller.gd` | 第一人称移动、镜头、真实水平速度、枪模反馈 |
| `training_target.gd` | 头身碰撞、固定路线移动、生命护甲与刷新 |
| `arena.gd` | 场地、墙体、灯光、六个靶子和测试装置 |
| `game_hud.gd` | 中文菜单、购买、准星、状态与结算 |

以 Godot 信号传递开火、命中、成绩和阶段变化，界面不负责伤害结算。所有玩法使用可暂停的游戏时间；按键时先检查开火许可，物理帧发射前再次检查，失败点击不会延迟补射。不设计外部 API。

移动默认最大速度 6 m/s、普通加速度 30 m/s²、松键减速度 12 m/s²、反向加速度 48 m/s²，物理频率 120 Hz。鼠标灵敏度及移动手感位于玩家模块；武器价格和换弹时间位于规则模块。枪模后移仅为视觉反馈，不改变准星方向。

## 运行与 Windows 导出

使用 **Godot 4.7.2 Standard（无需 .NET）** 验证，保留工程的 Forward Plus、Jolt Physics 和 Windows D3D12 配置。默认窗口 1280×720，最小窗口 960×540，界面随窗口缩放。中文字体随游戏打包，不依赖系统安装字体。

### 直接游玩

在仓库的 `builds/windows/` 或解压后的发布包中双击 `RMPrecisionLab.exe`。点击“开始训练”，在 15 秒内确认装备，进入场地等待训练开始。松开方向键或短按反向键，观察左下角速度比；满足门槛后点击开火。切换到其他窗口会自动暂停。

### 从工程运行

在 Godot 项目管理器导入 `射击游戏/project.godot`，等待字体导入后按 F6 运行主场景，或按 F5 运行项目。编辑器中场地不是预摆放的，运行时由脚本生成。

以下 PowerShell 命令从仓库根目录运行，把引擎路径替换为本机安装位置：

```powershell
$godotExe = 'D:\Downloads\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe'
& $godotExe --path '.\射击游戏' --editor --import --quit
& $godotExe --path '.\射击游戏'
```

### 测试与导出

```powershell
# 规则检查；真实场景检查
& $godotExe --headless --path '.\射击游戏' --script res://tests/test_rules.gd
& $godotExe --headless --path '.\射击游戏' -- --smoke-test

# 首次准备官方 Windows 模板（已有缓存可跳过）
python -m pip install requests
python tools/fetch_windows_template.py

# 导入资源、检查规则/场景、导出并复制文档和许可证
.\tools\build_windows.ps1 -GodotPath $godotExe

# 验证独立发布版本，包括鼠标瞄准与实际点击路径
.\builds\windows\RMPrecisionLab.exe -- --smoke-test
```

下载工具只从官方 4.7.2 模板 ZIP 读取 Windows x64 Release 部分（约 38 MB），校验 ZIP CRC；来源和 SHA256 记录于 `tools/cache/4.7.2-stable/download-receipt.json`。导出预设 `Windows Desktop` 使用该自定义模板并把游戏资源嵌入 EXE。也可在编辑器中将该模板改为本机匹配版本的 Release 模板。

构建脚本把临时目录与编辑器缓存放在 `artifacts/runtime/`，结束后恢复环境变量。构建物、测试截图和模板缓存已加入 Git 忽略规则；源码、字体及许可证保留在工程中。此版本只验证 Windows x64，不提供其他平台发布包。
